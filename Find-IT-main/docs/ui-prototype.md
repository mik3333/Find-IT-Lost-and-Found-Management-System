# User-Interface Prototype — FIND IT

The live prototype is the running website at `http://localhost:3000`.

## Visual direction

- Warm paper background, serif headings, short navigation labels
- Cards with photo thumbnails and titles on Home
- Lost vs found shown as small badges
- Forms stay on one column so a classroom projector remains readable

## Screens

1. **Home** — hero, filters (search, category, type, A–Z / latest), thread grid
2. **Log in / Register** — email and password; register also asks for public username
3. **Post a thread** — lost/found, category, title, description, location, date, image
4. **Item detail** — large photo, metadata, claim form, admin status control
5. **View profile** — avatar, username, password change, personal claim list
6. **Admin** — counts, pending claims, category totals, user list
7. **FAQs** and **Terms and Policies** — static policy pages

## Taskbar (navigation)

Home · FAQs · Terms and Policies · Post a thread · View profile · Log out  
Admin appears only for the administrator account.

## Wireflow

Register/Login → Home (browse/filter) → Item detail → Claim  
or Home → Post a thread → Item appears in grid  
Admin → Pending claim → Approve → Status becomes claimed

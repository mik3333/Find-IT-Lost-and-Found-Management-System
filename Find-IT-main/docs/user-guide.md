# User Guide — FIND IT

## Start the system

In the project folder:

```powershell
npm install
npm start
```

Visit `http://localhost:3000`.

## Create an account

1. Open **Log in**, then **Register**.
2. Enter email, public username, and a password of at least 8 characters.
3. You are signed in automatically.

On the first run, the server prints a randomly generated administrator login.
Use that email and password to sign in, and save the password securely.

## Browse and filter

On **Home**, use:

- Search box for words in the title, description, or location
- Category list
- Lost or Found
- Sort: **Latest upload** (default) or **Title A–Z**

Click a card to open the full thread.

## Post a thread

1. Choose **Post a thread**.
2. Select Lost or Found.
3. Add title, description, category, location, date, and optional photo.
4. Publish. The post appears on Home with a thumbnail.

## Request a claim

On someone else’s open item, write why the item is yours and submit. An administrator reviews it. You can see your requests under **View profile**.

## Edit your account

**View profile** lets you change:

- Public username
- Profile picture
- Password (current password required)

## Administrator tasks

After logging in as admin, open **Admin**:

- Read counts of users, reports, and claims
- Approve or reject pending claims
- Open an item and change status to reported, claimed, returned, or closed

## Policies

Read **FAQs** and **Terms and Policies** in the top navigation before presenting.
